paper2audio

Turn a scientific paper into an MP3 with one chapter per section — no citations, statistics, figure references or reference list. This page runs the full pipeline on GitHub's servers (GitHub Actions): paste a direct link to a PDF, press the green button, and pick up your MP3 a few minutes later. Nothing to install.

Convert a paper Must be a direct link to the PDF file (arXiv, bioRxiv, an open-access publisher page, a public URL…). Papers behind a paywall cannot be fetched.

Run the pipeline ▶

The button opens GitHub with the form pre-filled: press Run workflow there. You need to be logged in with write access to the repository (self-hosted means your GitHub runs it).

Your audio will appear under releases → web in a few minutes — see below.
